# 夜局 · 文字德州扑克

本地单机客户端。双击 `index.html` 即可开始，无需安装依赖；或运行 `npm start` 后访问 http://127.0.0.1:5173。

六人无限注德州扑克，起始筹码每人 2,000，盲注 10 / 20。支持四轮下注、最小加注、短码全下、加注权重开、主池与边池、平分底池和五张最佳牌比较。每手结束可继续，筹码延续；玩家破产或清桌后重新开局。

仅牌面图形化，其余通过文字传达，包括表情、思考、下注、输赢反应和桌边发言。可切换牌局节奏，轮到你时无限等待。F 弃牌 / C 过牌或跟注 / R 加注。

电脑采用不同风格的本地规则策略，只依据自己的底牌、公共牌及下注信息决策。表情存在伪装，不是牌力提示。当前不含联网真人对战、账号或存档，关闭页面结束本场。

运行 `npm test` 检查牌型、边池、下注及随机整场筹码守恒。

规则参考：https://www.pokerstars.com/poker/games/texas-holdem/

## 沉静牌桌界面

围桌人物使用 assets/players.png 透明图集，可通过顶栏「人物」切回纯文字；「纪事」可收起右栏。加注支持滑杆、数字输入与半池/一池快捷金额。所有全下路径（含全下跟注）均需二次确认；可以过牌时弃牌也会提示。人物目前使用静态姿态，尚未制作逐帧表情动画。
