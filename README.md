# 夜局 · 文字德州扑克

本地单机客户端。Windows 可双击根目录 `夜局.exe`；也可双击 `src/index.html`，或运行 `npm start` 后访问 http://127.0.0.1:5173。桌面开发使用 `npm run dev`，发布使用 `npm run build`，构建成功后自动更新根目录 EXE（需要 Rust 与 Tauri 构建环境）。

六人无限注德州扑克，起始筹码每人 2,000，盲注 10 / 20。支持四轮下注、最小加注、短码全下、加注权重开、主池与边池、平分底池和五张最佳牌比较。每手结束可继续，筹码延续；玩家破产或清桌后重新开局。

牌面与人物图形化，阿杰有六种短暂动作姿态，其余人物暂用静态形象；桌边发言和动作描述以文字传达，也可切换为纯文字人物模式。可切换牌局节奏，轮到你时无限等待。F 弃牌 / C 过牌或跟注 / R 加注。

电脑采用不同风格的本地规则策略，只依据自己的底牌、公共牌及下注信息决策。表情存在伪装，不是牌力提示。每手结算后自动保存筹码、庄位与手数；重开页面可继续下一手，进行中的一手不会保存。最近十手的文字回顾仅在本次打开期间可用。当前不含联网真人对战或账号。

运行 `npm test` 检查牌型、边池、下注及随机整场筹码守恒。

规则参考：https://www.pokerstars.com/poker/games/texas-holdem/

## 沉静牌桌界面

围桌人物使用 [透明图集](src/assets/README.md)，可通过顶栏「人物」切回纯文字；「纪事」可收起右栏。加注支持滑杆、数字输入与半池/一池快捷金额，非法金额会就近提示。所有全下路径（含全下跟注）均需二次确认；可以过牌时弃牌也会提示。结算后可从纪事栏查看最近十手回顾。
